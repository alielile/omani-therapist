# 🕌 Omani Therapist Voice AI

> **Simple voice chatbot for mental health support in Omani Arabic**

## 🎯 What It Does

Voice chatbot for mental health support in Omani Arabic dialect. Simple, fast, culturally sensitive.

## ✨ Simple Architecture

```
Voice Input → Web Speech API (STT) → AI → Web Speech API (TTS) → Voice Output
```

**Fast responses under 5 seconds** - no complex pipelines, just browser APIs + AI.

## 🚀 Quick Start

1. Open `index.html` in Chrome/Safari/Edge
2. Allow microphone access
3. Add AI API key (optional)
4. Click mic and talk in Omani Arabic!

```bash
# Optional: Local server
python -m http.server 8000
```

## 🛠️ Tech Stack

- **STT/TTS**: Browser Web Speech API
- **AI**: Any model (GPT-4, Claude, etc.)
- **Files**: Just 3 files - `index.html`, `app.js`, `README.md`

## 🇴🇲 Omani Features

- Authentic Omani Arabic dialect
- Islamic values and cultural sensitivity
- Family-focused therapeutic guidance
